# Guideline catalog

What a parent should do when, from pregnancy to age 9, with the source for each row. Compiled 2026-11-14 as raw material for the rules engine (`api/internal/rules`).

| File | Covers |
| --- | --- |
| [pregnancy.md](pregnancy.md) | Preconception to birth |
| [postpartum.md](postpartum.md) | The parent who gave birth, birth to 12 months |
| [baby-0-24m.md](baby-0-24m.md) | Baby visits, vaccines, feeding, sleep, milestones |
| [child-2-9y.md](child-2-9y.md) | Toddler, preschool and school age |

Each row has a timing, the action, a category, a source link and the date the source was opened.

Rows marked "(verify)" cite a page that was not opened, was blocked, or returned 404 when the links were checked on 2026-11-14. They stay out of rules until someone opens a working source and updates the row. A rule built from any other row still cites the page itself and its checked date, as `AGENTS.md` requires.

Many AAP and ACOG pages answer automated requests with 403. Those links work in a browser and are not marked for that reason alone.
